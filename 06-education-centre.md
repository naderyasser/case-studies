# Education Centre Management — [repo](https://github.com/naderyasser/SYSeducore)

**Kind:** the back office of a tutoring centre — students, teachers, groups, attendance and money

## What it does
| Area | |
|---|---|
| Students | a complete file per student, a unique code, a barcode ID card, thermal sticker labels |
| Teachers | profiles with several specialisations |
| Groups | timetables that detect room clashes automatically |
| Attendance | scan the code → status at once, recorded automatically |
| Payments | monthly fees per group and the teacher's settlement |
| Notifications | automatic WhatsApp for attendance, absence and payment reminders |
| Reports | dashboard, attendance and finance reports, activity log |

**982 automated tests.**

`Django 5` `DRF` `PostgreSQL` `Redis` `Celery` `ReportLab` `openpyxl` `PWA` `Docker`
